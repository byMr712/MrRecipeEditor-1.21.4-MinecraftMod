Универсальный внутриигровой редактор и студия создания рецептов для **Minecraft 1.21.4 (Fabric)**.

---

## О моде

**Recipe Editor** предоставляет полноценный внутриигровой графический интерфейс для просмотра, декомпиляции, создания и тонкой настройки рецептов крафта для любых предметов (ванильных и из сторонних модификаций). Мод поддерживает 7 типов рабочих станций, Drag & Drop управление, теги предметов, автоматическое предотвращение конфликтов рецептов и клиент-серверную синхронизацию на выделенных серверах.

## Возможности

- **Поддержка 7 типов рабочих станций:**
  - **Верстак** — сетка 3x3 для крафтов любой формы.
  - **Печь** — плавка предметов с настройкой времени и опыта.
  - **Плавильня** — ускоренная переплавка руд и экипировки.
  - **Коптильня** — ускоренное приготовление пищи.
  - **Камнерез** — распил блоков с динамической генерацией кнопок выбора вариантов в интерфейсе.
  - **Кузнечный стол** — трансформация экипировки с 3 слотами (шаблон, основа, материал).
  - **Костёр** — приготовление пищи на костре.
- **Управление мышью и Drag & Drop:**
  - Перетаскивание предметов из каталога в слоты крафта (ЛКМ).
  - Быстрая декомпиляция существующего рецепта предмета из каталога (ПКМ).
  - Очистка выбранного слота кликом ПКМ или клавишей `Del` / `Backspace`.
- **Поддержка тегов предметов (`#tag`):**
  - Поддержка ванильных и сторонних тегов (например, `#minecraft:planks`, `#c:iron_ores`, `#minecraft:sand`).
  - Проверка соответствия через `Ingredient.test()`.
- **Защита от конфликтов рецептов:**
  - Автоматическая проверка пересечений шаблонов крафта с ванильными и модовыми рецептами.
  - Информационное окно блокировки сохранения с визуализацией конфликтующего рецепта.
- **Многовариантность крафтов:**
  - Создание нескольких альтернативных вариантов рецепта для одного и того же предмета.
- **Сетевая синхронизация (Dedicated Server & LAN):**
  - Сетевой протокол на базе Fabric Networking API (`UpdateRecipeC2SPacket` / `SyncRecipesS2CPacket`).
  - Проверка прав оператора (уровень 2) на сервере и мгновенная синхронизация со всеми игроками.
- **Каталог предметов и фильтрация:**
  - Режимы фильтрации: «Все», «Без крафта», «С крафтом», «Мои крафты».
  - Вкладки модов (Mod Tabs) с горизонтальной прокруткой.
  - Полнотекстовый поиск по названиям (RU / EN) и ID предметов.
  - Адаптивная сетка под размер окна и масштаб GUI.
- **Интеграция с модами просмотра рецептов:**
  - Совместимость с JEI, REI, EMI и ванильной Книгой рецептов.

## Управление в редакторе

| Действие | Описание |
|---|---|
| **ЛКМ по предмету** | Выбрать предмет или перетащить его в слот сетки крафта |
| **ПКМ по предмету в каталоге** | Загрузить и декомпилировать рецепт предмета в редактор |
| **ПКМ по слоту крафта** | Очистить выбранный слот |
| **Клавиша `Del` / `Backspace`** | Очистить активный слот (или сбросить выбранный целевой предмет) |
| **Колёсико мыши** | Прокрутка страниц каталога предметов и вкладок модов |
| **Стрелки `◀` / `▶`** | Навигация по страницам станков и вариантам крафта |

## Конфигурация

Файл конфигурации сохраняется по пути: `config/recipeeditor.json`.

```json
{
  "modEnabled": true,
  "recipes": {
    "minecraft:totem_of_undying#SHAPED_CRAFTING#minecraft:golden_apple,...": {
      "id": "totem_of_undying_shaped",
      "resultItemId": "minecraft:totem_of_undying",
      "resultCount": 1,
      "type": "SHAPED_CRAFTING",
      "patternSlots": [
        "minecraft:golden_apple", "minecraft:golden_apple", "minecraft:golden_apple",
        "minecraft:golden_apple", "minecraft:ghast_tear",   "minecraft:golden_apple",
        "minecraft:golden_apple", "minecraft:golden_apple", "minecraft:golden_apple"
      ],
      "experience": 0.1,
      "cookingTime": 200,
      "enabled": true,
      "overrideExisting": false
    }
  }
}
```

## Установка

1. Скачайте последнюю версию мода со страницы [GitHub Releases](https://github.com/byMr712/RecipeEditor-MinecraftMod/releases).
2. Требуются:
   - [Fabric API](https://modrinth.com/mod/fabric-api)
   - [Mod Menu](https://modrinth.com/mod/modmenu)
3. Поместите `.jar` файл в папку `mods`.
4. Запустите игру.

---

## Сборка

1. Требуется Java 21 и Fabric Loader для Minecraft 1.21.4.
2. Для сборки выполните:
   ```bash
   ./gradlew build
   ```
3. Собранный файл находится в `build/libs/RecipeEditor-1.21.4-byMr712.jar`.
