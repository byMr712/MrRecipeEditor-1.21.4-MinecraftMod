## О моде

**[MR] Recipe Editor** — удобный внутриигровой редактор рецептов прямо в Minecraft! Больше не нужно копаться в текстовых файлах конфигураций или датапаках: открывайте меню редактора прямо во время игры через кнопку **Mod Menu** (в меню паузы/списке модов), перетаскивайте любые предметы мышкой и создавайте новые рецепты крафта для любых предметов — как из ванильного Minecraft, так и из любых установленных модов.

## Что умеет мод?

### Интеграция с модами и просмотр крафтов
- Можно редактировать рецепты из модификаций! Всё сортируется по группам.
- Созданные и переопределённые рецепты полноценно отображаются в стандартной книге рецептов верстака и печей Minecraft с возможностью быстрого автокрафта в один клик.
- Поддержка просмотра рецептов: официальная интеграция с **[Roughly Enough Items (REI)](https://www.curseforge.com/minecraft/mc-mods/roughly-enough-items)** через API — все кастомные рецепты сразу видны в поиске рецептов и использований, а переопределённые ванильные крафты скрываются.

### Поддержка 7 видов станков и верстаков
- **Верстак** — удобная сетка 3x3. Маленькие крафты (2x2 или 1x2, например факелы или палки) работают в любом месте сетки верстака.
- **Печь** — плавка руд и предметов с удобной настройкой времени приготовления (с подсказкой в секундах) и опыта.
- **Плавильня** — быстрая переплавка руды, брони и инструментов.
- **Коптильня** — быстрая готовка еды.
- **Камнерез** — распил камня и блоков.
- **Кузнечный стол** — создание и улучшение экипировки по шаблонам (3 слота).
- **Костёр** — простая жарка еды без топлива.

### Удобное управление и возможности
- **Мышка (Drag & Drop):** зажали левой кнопкой мыши (ЛКМ) любой предмет из каталога справа — перетащили в нужный слот крафта.
- **Инспектор рецептов:** нажали правой кнопкой мыши (ПКМ) по любому предмету в каталоге — мод сразу покажет его готовый рецепт в сетке.
- **Переопределение и восстановление крафтов:** редактирование уже существующего рецепта предмета переопределяет его в игре без дубликатов вариантов. А если удалить кастомный рецепт из «Моих крафтов» — оригинальный ванильный или модовый рецепт мгновенно восстанавливается и снова работает!
- **Несколько вариантов рецепта:** создавайте альтернативные способы получения любимого предмета с помощью кнопки `+` и легко переключайтесь между ними стрелками или колёсиком мыши прямо над окном крафта (они оба будут работать в игре).
- **Очистка слотов:** правый клик по слоту или клавиша `Delete`.
- **Защита от конфликтов рецептов:** если создаваемая форма крафта уже занята другим предметом, мод предупредит вас и покажет, какой предмет уже крафтится таким способом.
- **Быстрый каталог и поиск предметов:** фильтры «Все», «Без крафта», «С крафтом» и «Мои крафты», прокрутка вкладок модов колёсиком мыши и мгновенный поиск на любом языке.

### Ограничения модификации
- При загрузке и изменении уже имеющихся рецептов сохраняется поддержка групп предметов (тегов): рецепты, использующие «любые доски», «любую шерсть» или красители, продолжают принимать все вариации этих предметов при крафте. Для создания совершенно нового рецепта с нуля поддержка назначения произвольных тегов пока не предусмотрена.

## Управление в редакторе

| Действие | Описание |
|---|---|
| **Открыть меню редактора** | Открыть через кнопку **Mod Menu** в меню паузы (Esc) или главном меню |
| **ЛКМ по предмету** | Выбрать предмет или перетащить его в слот сетки крафта |
| **ПКМ по предмету в каталоге** | Загрузить и декомпилировать рецепт предмета в редактор |
| **ПКМ по слоту крафта** | Очистить выбранный слот |
| **Клавиша `Del` / `Backspace`** | Очистить активный слот (или сбросить выбранный целевой предмет) |
| **Клавиша `I`** | Включить или выключить отображение подсказок |
| **Колёсико мыши** | Прокрутка каталога предметов и вкладок модов, а при наведении на сетку крафта — переключение вариантов рецепта |
| **Стрелки `◀` / `▶`** | Навигация по страницам станков и вариантам крафта |

## Конфигурация

Файл конфигурации сохраняется по пути: `config/mrrecipeeditor.json`.

```json
{
  "modEnabled": true,
  "recipes": {
    "minecraft:totem_of_undying#SHAPED_CRAFTING#minecraft:golden_apple,...": {
      "id": "totem_of_undying_shaped",
      "resultItemId": "minecraft:totem_of_undying",
      "resultCount": 1,
      "type": "SHAPED_CRAFTING",
      "patternSlots": [
        "minecraft:golden_apple", "minecraft:golden_apple", "minecraft:golden_apple",
        "minecraft:golden_apple", "minecraft:ghast_tear",   "minecraft:golden_apple",
        "minecraft:golden_apple", "minecraft:golden_apple", "minecraft:golden_apple"
      ],
      "experience": 0.1,
      "cookingTime": 200,
      "enabled": true,
      "overrideExisting": false
    }
  }
}
```

## Установка

1. Скачайте последнюю версию мода со страницы на [CurseForge](https://www.curseforge.com/minecraft/mc-mods/mr-recipe-editor) или [GitHub Releases](https://github.com/byMr712/MrRecipeEditor-MinecraftMod/releases).
2. Требуются:
   - [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api)
   - [Mod Menu](https://www.curseforge.com/minecraft/mc-mods/modmenu)
3. Поместите `.jar` файл в папку `mods`.
4. Запустите игру.

## Сборка

1. Требуется Java 21 и Fabric Loader для Minecraft 1.21.6.
2. Для сборки выполните:
   ```bash
   ./gradlew build
   ```
3. Собранный файл находится в `build/libs/MrRecipeEditor-Fabric-1.21.6-byMr712-v1.4.jar`.
